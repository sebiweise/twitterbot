## TwitterBot

### Configuration
The functions read their credentials from environment variables (e.g. a `functions/.env` file, which is git-ignored):

- `OPENAI_API_KEY`, `OPENAI_ORGANIZATION` (optional)
- `TWITTER_CLIENT_ID`, `TWITTER_CLIENT_SECRET`
